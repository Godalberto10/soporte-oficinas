# Not receiving emails because the mailbox is full

## Symptoms
- The employee is not receiving new emails; other colleagues are.
- The warning "your mailbox has exceeded its size limit" appears.
- The office's `email` service is `ok`.

## Cause
The employee's mailbox has reached its maximum quota and the server rejects
incoming messages.

## Steps
1. Check the status of `email`; if it is not `ok`, follow `kb-email-01.md`.
2. Tell the employee to empty the "Deleted Items" folder and
   archive messages with large attachments.
3. Ask them to close and reopen Outlook.
4. If they need more mailbox quota, escalate to second level.
